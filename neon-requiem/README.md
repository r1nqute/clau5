# 네온 레퀴엠 (NEON REQUIEM)

2083년, 기업들이 세운 자유도시 할시온. 당신은 운반책이다. 습격이 틀어진 밤, 손목에 수갑으로 채워진 은색 케이스 속에서 아홉 살 아이의 목소리가 깨어난다. 사흘 뒤 자정, 그 아이를 「펜」 삼아 도시 전체의 기억이 다시 쓰인다.

선택지로 진행하는 스토리 중심 사이버펑크 로그라이크입니다. 한 판은 40~60분, 죽으면 처음부터 다시 시작하지만 에코(영구 강화)와 기억은 다음 시뮬레이션으로 이어집니다.

## 플레이

- `dist/neon-requiem.html` 파일 하나를 브라우저로 열면 바로 플레이할 수 있습니다.
- 개발 중에는 `index.html`을 열면 원본 CSS·JS 파일을 그대로 불러옵니다.
- 선택지는 마우스나 숫자 키(1~9), 진행은 Enter.
- 진행 기록은 브라우저의 localStorage에 저장됩니다.

## 구성

| 항목 | 내용 |
| --- | --- |
| 막 | 프롤로그 「검은 비」 → 1막 「더 웰스」 → 2막 「크롬 바자르」 → 3막 「백야 스파이어」 |
| 장면 | 111개 (스토리 비트, 막별 무작위 사건, 미확인 신호, 교전, 상점, 은신처 대화) |
| 출신 | 용병 · 넷 다이버 · 협잡꾼 · 기업 탈주자(2막 도달 시 해금) |
| 동료 | 곰(격투가) · 시안(다이버) · 파드레(거리 의사) — 각자 개인 이야기와 충성도 분기 |
| 결말 | 10종 — 죽음 2, 중도 1, 최종 결말 6, 진 결말 1 |
| 메타 | 에코 강화 7종, 미아의 기억 7조각, 데이터 파일 18건, 결말 도감 |

## 규칙 요약

- **능력치**: 무력 · 반사 · 해킹 · 화술. 판정 성공률 = 15 + 15×능력치 ± 상황 보정 (5~95%), 화면에 그대로 표시됩니다.
- **체력**: 0이 되면 플랫라인. 체력 30% 이하에서는 모든 판정 −10%.
- **인간성**: 사이버웨어 시술과 잔혹한 선택으로 깎이며, 0이 되면 크롬 광증.
- **열기**: 두 구역마다 1씩 오르고, 높을수록 매복 확률이 커집니다. 은신처·위조 신분으로 낮춥니다.
- **유대**: 미아와의 관계. 특정 선택지와 결말이 유대 수치로 열립니다.
- **전투**: 매 라운드 적의 태세에 따라 성공률이 바뀌고, 실패하면 반격을 받습니다. 아이템으로 흐름을 바꿀 수 있습니다.
- **지도**: 매 구역마다 사건·교전·암시장·시술소·은신처·미확인 신호 중 하나를 고릅니다.

## 개발

```
index.html          개발용 진입점 (원본 파일을 순서대로 로드)
css/style.css       스타일
js/engine.js        엔진: 상태, 판정, 효과, 전투, 상점, 메타 진행, 렌더링
js/data/core.js     아이템, 사이버웨어, 적, 출신, 동료, 강화, 데이터 파일, 기억, 막 구성
js/data/act0-1.js   프롤로그 · 1막
js/data/act2.js     2막
js/data/act3.js     3막 · 최종 장면
js/data/common.js   은신처 대화, 공통 사건, 미확인 신호
js/data/endings.js  결말과 에필로그
tools/check.js      데이터 검증기 + 자동 플레이 봇
tools/build.py      단일 HTML 번들러
```

```sh
node tools/check.js               # 장면·아이템·적·플래그 참조 정적 검증
node tools/check.js --sim 2000    # 무작위·전략·일반 봇으로 각 2000판 시뮬레이션
node tools/check.js --campaign 30 # 메타 진행을 누적해 진 결말 도달 판수 측정
python3 tools/build.py            # dist/neon-requiem.html 생성
```

현재 밸런스(강화 없음 기준): 화면에 보이는 정보만으로 고르는 봇은 약 25%가 사망하고 75%가 결말에 도달합니다. 진 결말은 최소 3판째부터 가능하며, 모든 정보를 아는 봇 기준 평균 4~5판이 걸립니다.

## 설정에 대해

사이버펑크 장르(네온 거대 도시, 메가코프, 사이버웨어, 넷 다이빙, 픽서)의 분위기를 따르지만, 도시·기업·인물·사건은 모두 이 게임을 위해 새로 만든 것입니다.
